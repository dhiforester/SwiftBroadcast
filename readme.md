# SwiftBroadcast - Sistem Manajemen dan Penawaran via WhatsApp
## Deskripsi
SwiftBroadcast adalah aplikasi berbasis web yang dirancang untuk membantu pengelolaan kontak, manajemen data produk, serta mengirimkan penawaran langsung melalui WhatsApp. Aplikasi ini cocok untuk bisnis yang ingin meningkatkan efisiensi dalam komunikasi dan pemasaran dengan pelanggan.
## Fitur Utama
- Manajemen Kontak: Tambah, edit, dan hapus daftar kontak pelanggan.
- Kelola Data Produk: Simpan dan kelola informasi produk secara sistematis.
- Penawaran via WhatsApp: Kirim pesan penawaran secara otomatis ke daftar kontak terpilih.
- Template Pesan: Buat dan gunakan template pesan untuk pengiriman yang lebih cepat.
- Histori Pengiriman: Melihat daftar pesan yang telah dikirim.
- User Management: Sistem login dan manajemen hak akses pengguna.
- UI Responsif: Menggunakan Bootstrap untuk tampilan yang menarik dan mobile-friendly.

## Teknologi yang Digunakan
- Backend: PHP 7.4
- Database: MySQL
- Frontend: jQuery, Bootstrap
- WhatsApp API: Terintegrasi dengan API WhatsApp untuk pengiriman pesan otomatis.
